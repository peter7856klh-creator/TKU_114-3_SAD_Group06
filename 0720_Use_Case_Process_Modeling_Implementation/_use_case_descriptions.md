# 使用案例描述

## UC-01：建立揪團

- 目標：團主能建立新的共乘揪團並讓其他人看見。
- 主要參與者：團主
- 支援參與者：系統
- 觸發事件：團主提交發起揪團表單
- 前置條件：團主已進入發起表單且具備基本資訊。
- 成功後置條件：揪團資料已建立並顯示於看板。
- 最低保證：若欄位不足或數值不合法，系統顯示錯誤訊息並阻止建立。

## UC-04：加入揪團

- 目標：團員能加入現有揪團並獲得分攤結果。
- 主要參與者：團員
- 支援參與者：系統
- 觸發事件：團員點擊加入按鈕
- 前置條件：揪團資料已建立且仍有空位。
- 成功後置條件：團員加入成功，名單更新，分攤結果顯示。
- 最低保證：若人數已滿，系統顯示已滿額並拒絕加入。

## UC-05：檢視分攤金額

- 目標：團員加入後可立即查看每人應付金額。
- 主要參與者：團員
- 支援參與者：系統
- 觸發事件：加入成功後重新計算分攤
- 成功條件：畫面顯示正確分攤結果。
