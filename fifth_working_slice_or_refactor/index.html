📌 分析模型與 BCE 職責架構 (Model Baseline)

本系統嚴格遵守 Boundary-Control-Entity (BCE) 責任分工與狀態轉移守衛規則：

  • Boundary BoardView / FormView：負責接收使用者觸發事件並渲染 DOM，不參與金額運算與狀態邏輯。
  • Control GroupController：處理 UC-01 至 UC-03 業務流程，校驗輸入合法性與狀態轉換（拒絕非法轉移）。
  • Entity Group / JoinRecord / User：保存揪團核心資料與成員清單，計算即時平攤費用 TotalCost / CurrentMembers。
  • State 狀態機生命週期：open (招募中) → full (滿額) → closed (已關閉)。
