# Code Agent Implementation Brief

## 1. 專案背景

本次原型是校園揪團與共乘／分攤平台，目標是在有限時間內完成一個可操作的第一個切片，讓使用者能發起揪團、加入揪團與查看分攤計算結果。

## 2. 目標角色

| 角色 | 主要任務 | 主要痛點 |
| ---- | -------- | -------- |
| 團主 | 發起揪團、設定人數上限與總車資 | 發起流程繁瑣，缺少明確成團狀態 |
| 團員 | 瀏覽看板、加入揪團、查看分攤金額 | 很難快速找到適合自己的對象與計算金額 |

## 3. 第一個可操作切片（First Working Slice）

本次只做「團主發起揪團，團員加入後可看到分攤金額，且人數滿額時顯示已滿額」。

## 4. 本期範圍內項目（In-Scope）

- 發起揪團表單
- 首頁看板顯示
- 加入揪團流程
- 分攤計算
- 滿額防呆與狀態顯示

## 5. 本期範圍外項目（Out-of-Scope）

- Google Maps 導航
- 即時聊天室
- 簡訊與 Email 通知
- 線上金流
- 正式登入與資料庫

## 6. 本次要實作的需求

| 需求編號 | 來源編號 | 需求描述 | 驗收條件 | 對應畫面或操作 |
| -------- | -------- | -------- | -------- | -------------- |
| FR-01 | INT-01 | 團主可輸入出發地、目的地、時間、人數上限與預估總車資 | 表單送出後，資料會出現在看板 | 發起揪團表單 |
| FR-02 | OBS-01 | 使用者可在首頁看板看到可加入的揪團 | 看板顯示至少 1 筆揪團資料 | 首頁看板 |
| FR-03 | INT-02 | 團員加入後可看到分攤金額 | 加入後畫面顯示每人應分攤金額 | 加入揪團流程 |
| NFR-01 | INT-01 | 系統應顯示加入人數與剩餘名額 | 使用者可在畫面上看到目前人數與空位 | 揪團卡片與詳細頁 |

## 7. 技術限制（Technical Constraints）

| 限制項目 | 本組設定 |
| -------- | -------- |
| 前端技術 | HTML、CSS、JavaScript |
| 後端技術 | 不使用正式後端，先用假資料 |
| 資料儲存 | 暫時使用前端陣列或 localStorage |
| 是否需要正式部署 | 否 |
| 是否允許外部套件 | 僅允許少量簡單套件，避免增加複雜度 |
| 是否允許正式登入 | 否 |

## 8. 程式碼代理不可自行決定的事項

- 不得自行新增即時聊天室、地圖導航或金流功能
- 不得自行改變本期核心任務
- 不得把需求來源改成與本組專案不符的內容

## 9. 若代理想加入，必須拒絕的功能

| 功能 | 拒絕理由 | 對應範圍外項目 |
| ---- | -------- | -------------- |
| 地圖導航 | 本期不納入，且會增加技術與時間成本 | Google Maps 導航 |
| 即時聊天室 | 會擴大範圍，且非本期核心任務 | 即時聊天室 |
| 線上金流 | 超出本期目的與原型範圍 | 線上金流 |
