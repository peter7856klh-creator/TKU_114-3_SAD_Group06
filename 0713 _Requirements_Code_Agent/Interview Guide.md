# Interview Guide

## 角色 1：團主（發起人）

| 題號 | 訪談問題 | 想確認的需求或風險 |
| ---- | -------- | ------------------ |
| 1 | 你平常是怎麼發起共乘揪團？ | 確認現況流程與痛點 |
| 2 | 發起揪團時最重要的資訊是什麼？ | 確認欄位需求 |
| 3 | 你最擔心的情況是什麼？例如人數超額、資訊不完整或計算錯誤？ | 確認風險與防呆需求 |
| 4 | 你希望系統在成團後可以自動幫你做什麼？ | 確認自動化與流程簡化 |
| 5 | 你是否希望系統顯示目前加入人數與剩餘名額？ | 確認成團狀態顯示需求 |
| 6 | 如果要做一個簡單的原型，你認為最重要的三個功能是什麼？ | 確認核心任務 |

## 角色 2：團員（加入者）

| 題號 | 訪談問題 | 想確認的需求或風險 |
| ---- | -------- | ------------------ |
| 1 | 你通常是如何找到共乘對象？ | 確認現況方式 |
| 2 | 你認為一個好的共乘平台最重要的是什麼？ | 確認使用者期待 |
| 3 | 你會希望加入後立刻看到哪些資訊？ | 確認加入後畫面需求 |
| 4 | 你是否會在意每個人要分攤多少錢？ | 確認分攤計算需求 |
| 5 | 若人數已滿額，你希望系統如何處理？ | 確認滿額防呆需求 |
| 6 | 若平台功能太多，你會不會覺得難用？ | 確認簡潔介面與範圍控制 |
