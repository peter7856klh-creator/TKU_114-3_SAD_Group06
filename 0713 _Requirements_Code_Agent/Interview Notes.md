# Interview Notes

## 訪談紀錄

| 受訪角色 | 問題摘要 | 回答摘要 | 追問 | 可能需求 | 不確定處 |
| -------- | -------- | -------- | ---- | -------- | -------- |
| 團主 | 發起揪團需要填哪些資訊 | 需要填出發地、目的地、時間與人數上限 | 是否需要填總車資？ | 發起表單與預估總車資欄位 | 是否需要地點選單 |
| 團主 | 成團後要不要自動通知 | 簡單顯示狀態即可，不一定要通知 | 是否需要即時更新？ | 狀態更新與剩餘名額顯示 | 通知機制屬範圍外 |
| 團員 | 加入後想看到什麼 | 想知道自己應分攤多少錢 | 是否要看所有成員名單？ | 動態分攤計算與成員清單 | 是否需要聊天室 |
| 團員 | 人數滿額怎麼辦 | 希望系統直接阻止再次加入 | 是否要顯示候補？ | 已滿額防呆 | 候補功能暫不納入 |
| 一般使用者 | 瀏覽看板的需求 | 想快速看到可加入的揪團 | 是否要篩選功能？ | 看板瀏覽與簡單篩選 | 地圖功能先不做 |
