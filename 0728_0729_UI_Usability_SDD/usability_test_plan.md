# 可用性測試計畫 (Usability Test Plan)

## N. 可用性測試任務卡

| 欄位 | 內容 |
| --- | --- |
| 任務編號 | UT-01 |
| 角色與情境 | 你是一位淡江大學學生，今晚需要搭乘共乘計車前往台北車站，希望尋找現有揪團並報名。 |
| 使用者目標 | 成功找到並加入一筆符合條件的共乘揪團。 |
| 起點 | 系統首頁 (UI-01)。 |
| 成功條件 | 進入目標揪團頁面，點擊報名並看到「報名成功」狀態。 |
| 部分完成 | 找到揪團但卡在確認頁面，經提示後才完成。 |
| 失敗判準 | 放棄操作、離開網站或報名錯活動且無法自行修正。 |
| 觀察指標 | 完成任務時間 (Sec)、點擊錯誤次數、遲疑時間。 |
| 中立追問 | 「你現在畫面上看到什麼？」、「你預期點這個按鈕會發生什麼事？」 |
| 不可提示 | 不要說出「點擊右上方申請報名按鈕」。 |
| 測試資料 | 預設揪團卡片：【7/28 20:00 側門至北車共乘】。 |
| 任務後問題 | 「你覺得剛才的報名流程順暢嗎？有沒有哪個地方讓你猶豫？」 |
