# 無障礙檢核報告 (Accessibility Check)

## I. 無障礙檢核結果

| 項目 | 結果 | 證據 | 修正 |
| --- | --- | --- | --- |
| 文字與背景對比 | 通過 | 主要文字對比度 ≥ 4.5:1 | 無 |
| 不只依顏色傳達 | 通過 | 狀態「額滿」除了灰色外加上文字與鎖頭圖示 | 無 |
| 鍵盤可操作 | 需修正 | Modal 彈窗開啟時 Tab 鍵會穿透至背景 | 需加裝 Focus Trap |
| 焦點順序 | 通過 | 表單按 Tab 鍵依序由上至下、由左至右移動 | 無 |
| 欄位標籤 | 通過 | 所有 input 皆具備對應的 `<label>` 與 `id` | 無 |
| 錯誤與欄位關聯 | 通過 | 錯誤訊息使用 `aria-describedby` 綁定欄位 | 無 |
| 點擊目標 | 通過 | 按鈕與卡片點擊區域均 ≥ 44x44 px | 無 |
| 文字放大 | 通過 | 放大至 200% 時版面自動折行且無內容裁切 | 無 |
