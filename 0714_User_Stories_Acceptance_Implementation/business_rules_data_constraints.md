# 業務規則、資料需求與限制條件

## 業務規則

- BR-01：揪團人數上限必須為大於 0 的整數。
- BR-02：當加入人數達到上限時，系統不得再接受加入。
- BR-03：分攤金額以總車資除以加入人數計算，結果保留兩位小數。

## 資料需求

- DR-01：需保存出發地、目的地、時間、人數上限、總車資、目前加入人數與狀態。
- DR-02：需保存每位加入者的加入順序與該次分攤基準。
- DR-03：需保存每筆揪團的建立時間與更新時間。

## 限制條件

- CON-01：本期不串接 Google Maps、即時聊天室與金流功能。
- CON-02：本期以假資料與前端儲存方式實作，不使用正式資料庫。
- CON-03：本期不提供正式登入與外部通知功能。
