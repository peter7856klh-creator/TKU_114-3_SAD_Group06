# 驗收條件

## 驗收條件清單

- AC-01-01：團主填寫完整欄位並送出時，新揪團應出現在看板。
- AC-01-02：團主未填寫必要欄位時，系統應顯示錯誤訊息並拒絕建立。
- AC-01-03：當人數上限設為 1 時，系統仍可建立單人揪團。
- AC-02-01：首頁看板開啟時，系統應顯示揪團卡片與基本資訊。
- AC-02-02：當看板沒有任何揪團資料時，系統應顯示空狀態或提示訊息。
- AC-03-01：當揪團尚未滿額時，團員加入後應更新成員名單並顯示分攤金額。
- AC-03-02：當揪團人數已達上限時，系統應顯示已滿額並禁止加入。
- AC-04-01：當總車資為 1000、使用者數為 4 時，每人應顯示 250.00 元。
- AC-05-01：系統應清楚顯示人數與剩餘名額，且滿額時不會誤加入。
- AC-NFR-01-01：系統重新計算分攤結果時，應與預期值一致且不出現錯誤數值。

## 驗收重點
本次驗收條件涵蓋正常、例外、邊界與品質情境，讓需求可被重現與測試。
